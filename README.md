# 🛒 Blinkit Clone – Flutter Application

A modern **Blinkit Clone mobile application** built using **Flutter**, focusing on clean UI, smooth navigation, and a real-time grocery app user experience.  
This project demonstrates structured Flutter development, reusable widgets, and scalable folder architecture.

---

## 📱 App Overview

The Blinkit Clone app replicates the core flow of a grocery delivery platform, including splash screen, authentication flow, product browsing, cart management, and bottom navigation.  
The project is designed to be responsive, easy to extend, and suitable for real-world production-level Flutter apps.

---

## ✨ Features

- 🚀 Splash Screen with smooth transition
- 🔐 Login / Authentication UI
- 🏠 Home Screen with product categories
- 🗂 Category-wise product browsing
- 🛒 Cart Screen UI
- 🧭 Bottom Navigation Bar
- 🎨 Clean and reusable UI components
- 📱 Responsive design for different screen sizes
